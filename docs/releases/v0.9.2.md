macOS Meeting Recorder 首个独立仓库发布版：本地会议录音、离线字幕、说话人识别与回听。

## 下载

下载附件 **macos-meeting-recorder-0.9.2-macos-arm64.dmg**，拖动“会议录音.app”到 Applications 后，从“应用程序”打开。`Source code` 是源码，不是安装包。

- 仅 Apple Silicon（M 系列），macOS 15+；实时字幕需要 macOS 26+。
- **导出仍需安装 Python 3 和 FFmpeg**。已有 Homebrew 可运行 `brew install python ffmpeg`。
- 字幕及说话人模型需在应用设置中主动下载或导入，不随 DMG 分发。

## 首次打开与授权

**此版本使用 ad-hoc 临时签名，尚无 Developer ID 签名和 Apple 公证。**

确认来源后，先尝试打开应用，再到“系统设置 → 隐私与安全性”点击针对“会议录音”的“仍要打开”，按提示确认。无需关闭 Gatekeeper 或 SIP。[Apple 官方说明](https://support.apple.com/102445)

首次录音需允许“麦克风”和“屏幕与系统音频录制”；本应用只保存音频，不保存屏幕图像。授权后若系统要求退出重开，请按提示操作。

**[完整安装、授权和首次使用说明](https://github.com/nalansitan/macos-meeting-recorder/blob/v0.9.2/docs/install.md)**，DMG 内也附有可离线阅读的“安装与使用说明.txt”。建议先完成 20 秒录音、保存和回听测试，再用于正式会议。

## 本版内容

- 麦克风与系统声音双路录音、暂停、草稿恢复和 M4A / SRT 导出。
- macOS 26+ Apple 端侧实时字幕，按说话人变化拆分字幕。
- 本地多人识别、人工命名及跨会议声纹匹配；历史录音不自动回填姓名。
- 字幕同步回听、跳转、倍速和历史录音管理。
- 移除字幕工坊入口，独立运行；改进 Python / FFmpeg 查找。
- “关于”中加入作者 @nalansitan 和项目链接；采用 Apache-2.0。

## 已知限制与校验

软件回声消除为实验功能，默认关闭。短句、重叠发言、相似声音和跨会议匹配仍可能识别不准；长会议、蓝牙切换和休眠恢复需进一步实测。没有自动会议摘要或待办提取。

可下载同目录的 SHA256SUMS，执行 `shasum -a 256 -c SHA256SUMS` 验证 DMG。音频、字幕、姓名和声纹在本机处理，不上传会议内容。
