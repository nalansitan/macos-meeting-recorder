# 安装、授权与首次使用

适用于 macOS Meeting Recorder 的 DMG 发布版，作者 [@nalansitan](https://github.com/nalansitan)。

## 下载与系统要求

从 [GitHub Releases](https://github.com/nalansitan/macos-meeting-recorder/releases) 下载 `macos-meeting-recorder-<版本>-macos-arm64.dmg`。`Source code` 是源码，不是安装包。

- Apple Silicon Mac（M 系列）；不支持 Intel 安装包。
- macOS 15 或更新版本可以录音；离线实时字幕需要 macOS 26 或更新版本。
- 导出录音需要本机安装 Python 3 和 FFmpeg。DMG 不包含这两个运行依赖，也不包含字幕或说话人模型。

如果已经安装 Homebrew，可在终端执行：

```sh
brew install python ffmpeg
```

没有 Homebrew 时，请先按 https://brew.sh 的官方说明安装。安装依赖和下载模型需要联网，准备完成后录音、转写和识别在本机进行。

可选校验：把 DMG 和 Release 附件 `SHA256SUMS` 放在同一文件夹，在终端进入该目录执行 `shasum -a 256 -c SHA256SUMS`，应显示 `OK`。

## 安装

1. 如已安装旧版，先结束并保存录音，再退出应用。
2. 双击 DMG，将“会议录音.app”拖到同一窗口内的 Applications 快捷方式。
3. 等待复制完成，推出磁盘映像，然后从“应用程序”打开“会议录音”。请不要直接在 DMG 内运行。

替换应用不会主动删除录音或人员库。默认录音位置是 `~/Movies/会议录音/`，说话人模型和人员库位于 `~/Library/Application Support/MeetingRecorder/Speakers/`。

## 首次打开：签名与系统拦截

**本版本只有 ad-hoc 临时签名，没有 Apple Developer ID 签名，也没有经过 Apple 公证。** macOS 可能提示“无法验证开发者”或“Apple 无法检查是否包含恶意软件”。临时签名校验不代表 Apple 已验证开发者身份或应用安全性。

确认文件来自本项目的 GitHub Release 后：

1. 先在“应用程序”里尝试打开一次，关闭拦截提示。
2. 打开“系统设置 → 隐私与安全性”，向下找到针对“会议录音”的拦截记录。
3. 点击“仍要打开”（Open Anyway），按系统提示验证身份并确认打开。

这是针对单个应用的例外，不需要关闭 Gatekeeper、SIP 或全局安全检查。受组织管理的 Mac 可能禁止此操作，需要联系管理员。若提示文件损坏或包含恶意软件，先停止打开，重新下载并校验，向项目反馈；不要直接删除隔离属性来绕过提示。

操作依据：[Apple：在 Mac 上安全地打开 App](https://support.apple.com/102445)。不同 macOS 版本的文字可能略有差异。

## 录音权限

首次开始录音时，根据 macOS 提示授权：

- **麦克风**：用于录下你的发言。
- **屏幕与系统音频录制**（部分版本称“屏幕录制”）：用于采集电脑播放的会议声音；本应用不保存屏幕图像。

可在“系统设置 → 隐私与安全性”中检查这两项。若系统要求退出并重新打开，照提示操作。更新临时签名版本后，可能需要重新授权；不要在会议录音进行中更新应用。

## 第一次使用

1. 打开应用设置，确认麦克风和保存位置。
2. macOS 26+：选择字幕语言，并在设置中主动准备对应 Apple 语言模型。模型未准备好时，可以关闭字幕先使用录音；macOS 15 请关闭字幕。
3. 如需区分多人，在“说话人识别与姓名”中下载或导入本地 Core ML 模型，再开启识别。此项可选，模型不随安装包分发。
4. 建议佩戴耳机。点击“开始录音”，分别讲话、播放电脑声音，确认两路音量条有变化。
5. 先录制约 20 秒，点击“结束并保存”，确认 M4A 可回听；开启字幕时检查同名 SRT。正式会议前完成这次小测试。
6. 需要跨会议识别人名时，人工确认姓名并勾选“记住此人的声纹”。短句、混合声音或相似声纹可能无法匹配；历史录音不会自动补填姓名。

## 常见问题

- **保存提示缺少 Python 3 或 FFmpeg**：安装上述依赖后退出重开应用，再点“重试保存”。原始片段会保留。应用支持 PATH 和 Homebrew、MacPorts 常见安装位置。
- **没有麦克风声音**：检查所选输入设备、单路暂停状态和麦克风权限。
- **没有电脑声音**：检查屏幕与系统音频录制权限，以及电脑是否确实在播放声音。授权后按系统提示重启应用。
- **字幕不可用**：确认 macOS 版本、语言和本地模型状态；不会回退到云端转写。
- **扬声器声音重复录入**：优先使用耳机。软件回声消除为实验功能，默认关闭，需在自己的会议软件和设备上测试。

音频、字幕、声纹和姓名在本机处理，本应用不上传会议内容。系统音轨也会包含其他应用的播放声音。当前不提供自动会议摘要或待办提取。

更完整的功能、恢复边界和验证记录见 [使用与技术说明](https://github.com/nalansitan/macos-meeting-recorder/blob/main/docs/usage.md)。问题反馈：https://github.com/nalansitan/macos-meeting-recorder/issues
